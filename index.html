FEATURES

九大模块，贯通施工质量管控全流程

从规范知识检索到竣工资料归档，一个桌面软件完成

知识底座

规范标准（PDF）与项目案例（Word）自动解析切块、向量化入库，构建本地专业知识库。

技术问答

基于知识库回答岩土专业问题，答案逐条标注规范名称与条款号，可溯源、不臆造。

文件管理

建设、勘察、设计、施工、监理、检测六阶段分类，支持批量上传与系统默认程序打开。

文件审核

逐段对照规范条文判定合规性，按勘察规范核查必备章节完整性，意见可导出 Word 报告。

总平面图

CSV 批量导入桩位坐标自动成图，滚轮缩放、拖拽平移，风险等级颜色联动标注。

实时状态

钻进速度、电流、流量等参数仪表盘同屏展示，长螺旋钻具深度标尺随进尺实时伸缩。

单桩数据

27 项固定表头批量导入施工记录，按日期与设备筛选，环形进度对比设计总量。

风险预警

对桩位偏差、垂直度、桩长、充盈系数、电流分级预警，评级结果联动总平面图。

资料归档

依技术规程生成 29 项归档清单，自动匹配已有文件、标注缺失项，支持「不涉及」与恢复。

01

知识底座

规范标准、项目案例统一入库的智能基础，供问答与审核检索引用。

  • 支持 PDF / Word 文档解析，自动切块向量化
  • 逐文件显示「已入库 N 块 / 未入库」状态
  • 向量数据本地存储，知识库不出本机
02

技术问答

基于规范条文回答 CFG 桩专业问题，每条答案附引用出处。

  • 大模型 + RAG 检索增强生成，答案标注 [n] 编号
  • 右侧引用卡片列出规范名称、条款号与原文
  • 问答历史持久化保存，重启软件自动恢复
03

文件管理

按工程阶段分类的项目文件中心，六方协同、条理清晰。

  • 建设 / 勘察 / 设计 / 施工 / 监理 / 检测六阶段彩色标签
  • 支持子文件夹导航、批量上传与系统默认程序打开
  • 同名文件自动加时间戳后缀，杜绝误覆盖
04

文件审核

合规性与完整性双重把关，审核意见清单一目了然。

  • 逐段对照规范条文，判定符合 / 需补充 / 缺失
  • 依据勘察规范 9 项必备章节自动核查完整性
  • 审核结果一键导出 Word 报告
05

总平面图

数百根桩位坐标一图掌握，支持缩放平移与风险联动着色。

  • CSV 批量导入桩编号与 X / Y 坐标自动成图
  • 滚轮缩放、拖拽平移、自适应网格与比例尺
  • 桩点按预警等级着色，支持导出图片
06

实时状态

仪表盘与深度剖面直观还原长螺旋 CFG 桩成孔施工监控。

  • 下钻速度、提钻速度、实时电流三组仪表盘同屏
  • 长螺旋钻具从地面起延伸，随实际深度自适应伸缩
  • 导入桩机监控 Excel 即还原单桩施工全过程参数
07

单桩数据

27 项施工参数精细管理，进度统计对比设计总量。

  • Excel 第二列批量导入每根桩的施工记录
  • 按施工日期、桩机编号多维筛选
  • 环形进度图实时对比桩数、桩长设计总量
08

风险预警

关键指标逐项评估、分级预警，质量风险早发现。

  • 桩位偏差、垂直度、桩长、充盈系数、电流五项评估
  • 单桩风险量化偏差度，给出综合评级
  • 风险等级占比饼图，评级同步着色总平面图
09

资料归档

按技术规程归档清单自动匹配文件，竣工资料闭环管理。

  • 六大类 29 项归档资料，两列卡片布局进度可视
  • 绿底「已有」/ 红底「缺失」标签，关键词+手动双重匹配
  • 支持「不涉及」标记与恢复，内置 PDF/图片预览
